# Potions (48)

The only genre staples kept are **Healing Draught** and **Mana Potion**, which every fantasy game has. Every other potion is an original concept, many built around the Warband. Potion slots: 3 (2 on Ascension 4+). Drop odds and pity are unchanged from the reference design (PLAN §4).

**Art direction:** chunky readable bottle silhouettes, one per category: round flask = healing/support, tall vial = buff, jar = thrown/damage, odd vessel = rare/unique. One bold liquid colour each, with a small icon floating inside.
