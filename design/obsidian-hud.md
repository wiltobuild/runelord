# Current combat UI: Obsidian HUD

The user selected the sculpted basalt/bronze screenshot on 2026-10-02 and requested immediate game integration. The current UI uses `assets/ui/obsidian-hud/r1/template.png`, copied to `apps/web/public/ui/obsidian-template.png`. The raster was generated with the built-in image tool; its prompt and coordinate map are in the adjacent `manifest.json`. The selected reference is preserved there as `reference.png`.

The template is a transparent 1672 × 941 frame. Never bake counters, map art, card art, actors, or inventory contents into it. `HudTemplate.tsx` defines the reference dimensions and inventory socket coordinates. `hud.css` positions the live interface in those same native pixels, then uniformly scales the entire stage to fit the window, letterboxing when needed. New content should use these coordinates, not independent viewport breakpoints. Spell effects, floating numbers, and actor motion convert screen coordinates back into this space.

The warband heading, empty panel, and slot strip are removed. Summoning mechanics and actual allied actors remain available. Three item sockets and three potion sockets replace the textual inventory bars. The existing demo starts with Brand of the Pit and one Healing Draught, so the other four sockets are empty. This UI change does not add new inventory rewards, potion types, or alter combat balance. Brand opens its passive description; the potion invokes the existing single-use healing action. Empty sockets report that they are empty. Healing amount comes from max HP, not the reference screenshot's illustrative +15 label.

Mana glows and pulses on change, depleting its glow at zero. End Turn keeps the painted gem stationary: only its live lettering changes color/glow on hover or press, with an underline for keyboard focus and a resolving label during actions. No separate polygon, rotating box, or scaling effect is painted over the gem. Its text remains visible at small viewport widths. The encounter plaque uses native bounds (700, 0, 272, 40), centered on the stage at x=836, with two pixels of optical top padding. Cards retain selection, hover descriptions, target prompts, and unavailable-state feedback. Enemy health and intent remain live. Draw/discard counters open their current contents; the draw pile sorts by card ID so it does not disclose the shuffled order. Escape closes inspection/help/deck dialogs or cancels target selection; dialog keyboard focus is contained and restored. Reduced-motion preference disables decorative CSS motion.

Verification: production build and all 28 engine tests passed. Browser play verified Firebolt, Imp summon and immediate attack, end-turn resolution, healing and consumed-slot appearance, item inspection, discard inspection, Escape, save/resume, and layouts at 1672×941, 1280×720, and 960×540. Six inventory sockets rendered, zero empty-warband panels remained, and no broken images or browser errors were observed. Static artwork remains reviewable in the gallery; gallery approval is distinct from the user's authorization to integrate this design.
