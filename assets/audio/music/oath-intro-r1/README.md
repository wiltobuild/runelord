# Oath at the Infernal Gate

Original Runelord composition and procedural synthesis. No third-party samples, recordings or SoundFonts.

80 BPM, eight 4/4 bars, exactly 24 seconds / 1,152,000 stereo frames at 48 kHz. Fire accents at 0, 6, 12 and 18 seconds; stronger choir, horns and drums for the demon reveal at 12 seconds. Circular reverb and a 3 ms endpoint taper preserve the loop. Render: `node tools/audio/render-oath-intro.mjs`. Runtime WAV is intended for muxing into the parent cinematic so picture and score share one timeline. No player code modified. Technical validation does not substitute for subjective listening approval.
